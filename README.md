# Brain Games

**Brain Games** is a set of five console games based on popular mobile brain-training apps. Each game asks questions that require correct answers. Answering three questions in a row wins the game. A wrong answer ends the game and prompts you to try again.

## Games List:
* **Even** — determine if a number is even.
* **Calc** — calculate the result of arithmetic expressions.
* **GCD** — find the greatest common divisor of two numbers.
* **Progression** — find the missing number in an arithmetic progression.
* **Prime** — determine if a number is prime.

## Setup and Run

```bash
# Clone the repository
git clone git@github.com:ozmeks/java-project-61.git
cd java-project-61/app

# Build and run the application
make build
make run-dist
```
